Minecraft, Rebuilt in Rust.

Vyron is a native Minecraft 1.8.9 client built for PvP — with the Lunar-style mod suite baked in, per-server auto-compliance, and real textures pulled from your own copy of the game. No JVM. No Java runtime. Just speed.

Why Vyron

Everything a PvP player needs, built in

No mod folders, no jar juggling. The suite ships inside the client and updates with it.

Built-in PvP Suite

FPS, CPS, Keystrokes, Coordinates, Freelook, Zoom, Toggle Sprint/Sneak and Ping are live today — with Armor Status, Bedwars HUD and the rest of the 31-module suite rolling out.

9 of 31 modules live

Per-Server Auto-Compliance

Vyron knows the rules of the server you join. Modules a server disallows — like Freelook on Hypixel — switch themselves off automatically, so you never get flagged for a mod you forgot to disable.

Live

Real Textures, From Your Copy

Hit Prepare in the launcher and Vyron extracts the genuine block textures from your own Minecraft jar — the real look of the game, with zero assets bundled or redistributed.

Live

Native Rust Performance

A from-scratch engine in Rust — no JVM, no garbage-collection hitches. Instant startup, a tiny memory footprint, and frame rates the Java client can't touch on the same hardware.

Live

Friend Invite Codes

Hosting a world? Share a single VYRON invite code and your friends join straight from the launcher — no IP addresses, no port-forwarding guides, no Hamachi.

Live

Replay → Clip Export

Record your games and export the best moments as vertical clips, ready for Shorts and TikTok — built for players who also create.

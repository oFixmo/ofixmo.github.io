VYRON

Vyron is a modpack & client for Minecraft — rebuilt in Rust. Thirty-two mods built in, profiles for every playstyle, and none of the mod-folder wrangling. Move your cursor — the world behind this page is live.

Our Features

One install, the whole modpack built into the client — explore what Vyron has to offer

One download to launch

Single Install

One installer sets up the launcher and the native client. No Java runtime to install, no mod folders to manage — sign in and play.

32 mods · 12 live today

Countless Mods

The PvP suite is built in: FPS, CPS, Keystrokes, Freelook, Zoom, Armor Status, Potion Effects and more — every module native Rust, toggled in one menu. Twelve of the thirty-two modules are live today; the rest are in active development.

Native Rust engine

Boosted Frames

The game itself is reimplemented in Rust on wgpu/Vulkan — no JVM, no garbage-collection hitches, just a native binary built for PvP.

Windows first

MultiOS Support

Windows leads, with macOS and Linux builds on the roadmap — the same client, the same mods, on every OS.

Vyron is in active development. Follow the build milestone by milestone — every step of the Rust rebuild happens in the open, on GitHub.

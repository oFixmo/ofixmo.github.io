VYRON

A modpack-style client for Minecraft 1.8.9 — rebuilt in Rust.

⇩ Download for Windows View on GitHub
One download to launch

Single Install

One installer sets up the launcher, the client and the server. Open it, pick your account, press play — nothing else to configure.

31 modules · growing

Built-in Mods

A Lunar-style mod suite baked into the client — FPS, CPS, keystrokes, freelook, zoom and more, with per-server auto-compliance.

Native Rust · No JVM

Boosted Frames

The game itself is reimplemented in native Rust on wgpu/Vulkan — no Java runtime, no JVM overhead between you and the render.

Windows first

Multi-OS Support

Windows is the launch platform, cross-compiled and packaged today. macOS and Linux builds are on the roadmap, in the open.

Built in the open

Vyron is in active development. Follow the build, milestone by milestone.

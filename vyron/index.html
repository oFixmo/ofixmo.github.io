Our Features

Explore what Vyron has to offer

One download to launch

Single Install

One installer sets up the launcher and the native client. No Java runtime to install, no mod folders to manage — sign in and play.

31 mods and growing

Countless Mods

The PvP suite is built in: FPS, CPS, Keystrokes, Freelook, Zoom, Armor Status and more — every module native Rust, toggled in one menu.

Native Rust engine

Boosted Frames

The game itself is reimplemented in Rust on wgpu/Vulkan — no JVM, no garbage-collection hitches, just a native binary built for PvP.

Windows · macOS · Linux

MultiOS Support

Windows is available first, with macOS and Linux builds on the roadmap — the same client, the same mods, on every OS.

Vyron is in active development. Follow the build milestone by milestone — every step of the Rust rebuild happens in the open, on GitHub.
